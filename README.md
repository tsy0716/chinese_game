# 拼音宾果 · 中文词语卡片

给海外华裔孩子 / 周末中文学校用的中文词语卡片生成器。

一个词一格，可以印**汉字 + 逐字对齐的拼音**、**只印汉字**、或者**只印拼音**。
打印出来，裁判喊词，选手在自己卡上找到并标记。

**全班的卡词语完全相同，只有位置不同** —— 所以任何一张卡本身就是完整词表，
随便拿一张当喊词单就行，不需要另做。想要一张专门的，勾上「多印一张裁判页」。

**这个工具只负责出题面** —— 连几个算赢、横竖斜算不算、用棋子还是画圈，都由你自己定。

**在线使用：** https://tsy0716.github.io/chinese_toolbox/

不想联网也行 —— 把这个仓库下载成 zip 解压，双击 `index.html` 就能用。没有构建步骤，
没有依赖，没有服务器。

---

## 怎么用

1. 打开页面，勾几个主题（勾得越多词池越大）
2. 选**格子里印什么**、网格大小、填学生人数，点「生成卡片」
3. 点「打印」，一人发一张
4. 老师照着任意一张念，念过的划掉；孩子在自己卡上找到那个词就标记
   （豆子、棋子、画圈都行）

**多印一张裁判页**（默认不勾）—— 勾上会在最前面多加一页，抬头是「裁判用」、
没有姓名栏，老师撕走第一页即可。它的词和学生卡一模一样，但**摆法是独立的**：
否则会跟某个学生的卡长得一样，那孩子照着老师划掉的位置抄就行了。

## 三种显示方式

| 模式 | 用途 | 最大网格 |
|---|---|---|
| **汉字 + 拼音** | 认字起步阶段，拼音当拐杖 | 5x8 = 40 词 |
| **只印汉字** | 脱离拼音、直接认字 | 6x12 = 72 词 |
| **只印拼音** | 练拼读，听音找拼音 | 5x12 = 60 词 |

换模式时网格下拉会自动重建 —— 每种模式能撑住的密度不一样：

- **汉字+拼音** 内容最高（拼音压在汉字上方），保守停在 5x8。这也是单个主题
  （最少 41 词）还能独立铺满的上限。
- **只印汉字** 字号最宽松，7 列 16 行排 112 词字号都还有 6.3mm。真正卡住上限的
  **不是看不看得清，而是格子还够不够孩子放棋子 / 画圈** —— 所以停在 6x12，
  格子 32x18mm。
- **只印拼音** 卡在宽度上。`cháng fāng xíng` 这类长拼音会**自动折成两行**换取更大
  字号，即便如此 5x12（格子 38x18mm）也只到 5.8mm 了，5x14 就没法看了。

## 页面上的其它选项

**种子** — 每次生成会得到一个短码（如 `k3m9`），印在卡片右上角，格式是 `#02 · k3m9`。
孩子把卡弄丢了，把同一个种子填回去、人数设成一样，重新生成就是**一模一样的一批卡**。

**另外加词** — 这周新学的词直接粘进去，**只写汉字**，逗号或换行隔开：

```
苹果,香蕉,西瓜
榴莲、菠萝，芒果
# 井号开头的行会被忽略
```

拼音由程序标，不用你写。想自己写也行，写了的一律优先，程序不覆盖：

```
还给 huán gěi
```

自己写时**按音节分开，一个音节对一个汉字** —— 汉字+拼音模式下拼音是逐字标在汉字正
上方的，必须一一对应。写成连写的 `píngguǒ` 不会报错，但那一格会退化成「整串拼音居中」。

## 拼音是自动标的

用的是 [pinyin-pro](https://github.com/zh-lx/pinyin-pro)（MIT），打包在 `vendor/` 里，
**不走 CDN** —— 下载成 zip 双击 `index.html` 照样能标，不用联网。

多音字大多能按词义选对：长大 `zhǎng`、长短 `cháng`、银行 `háng`、行人 `xíng`、重新
`chóng`、会计 `kuài`、睡觉 `jiào`、音乐 `yuè`；「一 / 不」的变调也是对的（`yí gòng`、
`bú yào`）。

但它会走眼。实测标错的：

| 词 | 标成 | 应为 |
|---|---|---|
| 还给 / 还书 | `hái` | `huán` |
| 教书 | `jiào` | `jiāo` |
| 种花 | `zhǒng` | `zhòng` |
| 数数 | `shuò shuò` | `shǔ shù` |
| 系（单字） | `xì` | `jì` |

所以**凡是你自己加的词里含多音字的，状态栏都会单独点名**，让你核对。点「标上拼音，
填回框里」可以把标好的拼音填进输入框直接改 —— 改完的就是你写的，程序不再动它。

内置那 657 个词不会来烦你：它们的读音由 `node --test pinyin.test.js` 整库把关过。

轻声按这个库的习惯标，和教材略有出入 —— 它给 `táo zǐ`，教材写 `táo zi`。

## 打印注意

纸张选 **A4 竖向**，一页一张卡。

卡片总高 238mm，比 A4 的可打印高度（277mm）留了大截余量，所以**页眉页脚开着、
或者页边距被调大，都不会把一张卡劈成两页** —— 10 / 20 / 25mm 三种页边距 × 各模式
最密的网格全部实测过。

只是页眉页脚开着的话，页码和 `file:///...` 会印在卡片旁边。想干净一点，就在打印
对话框里关掉「页眉和页脚」。

## 内置词库

15 个主题，共 657 个词，都是海外中文学校的日常高频词，覆盖 HSK 1-2 的常用名词动词形容词：

数字与量词 · 家人与称呼 · 身体与健康 · 食物与餐具 · 水果与饮料 · 动物 · 颜色与形状 ·
衣服与穿戴 · 学校与文具 · 家与家具 · 天气与自然 · 时间与节日 · 常用动作 · 交通与地方 ·
心情与礼貌

每个主题都不少于 41 词，所以单选一个主题就能铺满「汉字+拼音」模式的最大网格。
更密的纯汉字 / 纯拼音网格需要多勾几个主题 —— 词不够时页面会直接提示。

### 加词 / 改词

改 `words.js`，在对应主题的数组里加一个字符串就行 —— **只写汉字，不用管拼音**：

```js
words: [
  '苹果', '香蕉', '西瓜', '榴莲',
],
```

加完跑测试：

```bash
node --test
```

`words.test.js` 会检查词是不是纯汉字（手滑写成 `'苹果 píng guǒ'` 会被抓出来）、
主题词数够不够铺满网格、有没有重复。`pinyin.test.js` 会把整个词库标一遍，音节数对不上
或者常见多音字标错立刻报出来。

**遇到怎么都标不对的词，换一个，别把错的注音印到卡片上。** 单字「系」（本义 `jì`）就是
这么被换成「鞋带」的。

## 字号是算出来的，不是调出来的

格子里用多大的字，由 `logic.js` 的 `cellFontSizes()` 按模式、格子尺寸、字数算出来，
不写在 CSS 里。这样才能对**657 个词 × 22 种网格 × 3 种模式**跑穷举验证：任何一个词
在任何一种网格里都不许溢出，主字号也不许低于下限（汉字 6mm，拼音 5.5mm —— 拉丁字母
笔画稀疏，同尺寸比汉字好认）。

拼音的宽度用的是**实际量出来的每字母字宽表**，不是平均值。一开始用「平均 0.55」这
一个常数，结果 `m` 实际有 0.855、`l` 只有 0.235，含 m 的词（`máng guǒ`、`gǎn mào`、
`bāng máng`）全都撑破格子。

## 测试

```bash
node --test
```

零依赖，不用 `npm install`。107 个测试分三部分：

- `test.js` — 排卡逻辑（带种子的随机数、洗牌、抽词、按种子重印、全班同词但摆法
  各不相同、词表解析、自动补拼音、拼音逐字对齐、长拼音折行）+ 字号的穷举验证
- `words.test.js` — 词库体检：是不是纯汉字、每个主题够不够铺满网格、同一主题内
  有没有重复词
- `pinyin.test.js` — 拼音质量：拿整个词库考 `vendor/pinyin-pro.js`，音节数必须等于
  汉字数、常见多音字不许标错、「一 / 不」变调要对。**升级这个库之后必须重跑**

单元测试算的是**模型**，实际渲染是不是真的不溢出，得在浏览器里量 —— 这两层缺一不可，
之前几个 bug（漏算 0.4mm 格线、漏算汉字列间隙、拼音字宽用平均值）都是浏览器抓出来的。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 + 打印样式（`@media print`） |
| `logic.js` | 纯函数：洗牌、抽词、排卡、词表解析、补拼音、拼音对齐、折行、字号计算。不碰 DOM，也不依赖拼音库（转换器是注入的），浏览器和 node 都能加载 |
| `words.js` | 词库数据 —— 只有汉字 |
| `vendor/pinyin-pro.js` | 打包进来的汉字转拼音库（MIT，见 `vendor/LICENSE-pinyin-pro.txt`）。地址栏里带的是**库自己的版本号**，改 app.js 不该让人重下这 324KB |
| `app.js` | 界面交互 |
| `test.js` `words.test.js` `pinyin.test.js` | 测试 |

全部用普通 `<script>` 标签加载，**不用 ES modules** —— 这样 `file://` 直接双击打开也能跑
（ES modules 会被浏览器的同源策略拦掉）。
