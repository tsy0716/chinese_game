# 拼音宾果 · 连四

给海外华裔孩子 / 周末中文学校用的中文词语宾果卡片生成器。

一个词一格，格子里印**汉字 + 逐字对齐的拼音**。打印出来，裁判喊词，选手在自己的卡上找到并标记，
横、竖、斜任意方向**连成 4 个**即获胜。

**在线使用：** https://tsy0716.github.io/chinese_game/

不想联网也行 —— 把这个仓库下载成 zip 解压，双击 `index.html` 就能用。没有构建步骤，
没有依赖，没有服务器。

---

## 怎么玩

1. 打开页面，勾几个主题（勾得越多词池越大）
2. 选网格大小、要印几张，点「生成卡片」
3. 点「打印卡片」，一人发一张
4. 老师用屏幕上的**喊词器**随机喊词（自动不重复，已喊的列在下面供核对），
   或者打印一张**喊词单**照着念、自己打勾
5. 孩子在卡上找到那个词就标记（豆子、棋子、画圈都行）
6. 谁先连成 4 个谁赢 —— 照着已喊列表逐格核对

## 页面上的几个选项

**网格** — 4x6（24 词，格子最大，低年级好认）/ 5x6（30 词，推荐）/ 5x7（35 词，期末复习量大）。

**每张卡词语相同，只打乱位置** — 勾上时全班用同一批词，只有摆放位置不同，
复习覆盖最均匀；不勾则每张卡从词池随机抽，喊到的词你卡上可能根本没有，惊喜感更强。
词池刚好等于格数时两者等价。

**种子** — 每次生成会得到一个短码（如 `k3m9`），印在卡片右上角，格式是 `#02 · k3m9-2`。
孩子把卡弄丢了，把同一个种子填回去、张数设成一样，重新生成就是**一模一样的一批卡**。

**另外加词** — 这周新学的词直接粘进去，每行一个：

```
苹果 píng guǒ
对不起 duì bu qǐ
# 井号开头的行会被忽略
```

拼音**按音节用空格分开，一个音节对一个汉字** —— 卡片上拼音是逐字标在汉字正上方的，
所以必须一一对应。写成连写的 `píngguǒ` 不会报错，但那一格会退化成「整串拼音居中」，
对不齐。

## 打印注意

在浏览器打印对话框里**关掉「页眉和页脚」**，边距选「默认」。否则页码和 `file:///...`
会印到卡片上。纸张选 A4 竖向。

## 内置词库

15 个主题，共 600 多个词，都是海外中文学校的日常高频词，覆盖 HSK 1-2 的常用名词动词形容词：

数字与量词 · 家人与称呼 · 身体与健康 · 食物与餐具 · 水果与饮料 · 动物 · 颜色与形状 ·
衣服与穿戴 · 学校与文具 · 家与家具 · 天气与自然 · 时间与节日 · 常用动作 · 交通与地方 ·
心情与礼貌

每个主题都不少于 35 词，所以**单选一个主题也能铺满最大的网格**。

### 加词 / 改词

改 `words.js`，在对应主题的数组里加一行 `['汉字', '拼 音']`。拼音规则：

- 音节之间空一格，**一个音节对一个汉字**（`['苹果', 'píng guǒ']`）
- 轻声不标调（`yī fu`、`mā ma`）
- 「一 / 不」按实际变调写（`yí gòng`、`bú kè qi`）
- 儿化音凑不出一一对应，避开（用「一点」而不是「一点儿」）

改完跑一下测试，写错会立刻报出是哪个主题的哪个词。

## 测试

```bash
node --test
```

零依赖，不用 `npm install`。57 个测试分两部分：

- `test.js` — 排卡逻辑：带种子的随机数、洗牌、抽词、卡片可按种子重印、
  同批卡两两不重复、连 4 判定的四个方向、自定义词表解析、拼音逐字对齐
- `words.test.js` — 词库体检：音节数是否等于汉字数、拼音有没有漏标声调 /
  混进汉字 / 用了数字声调、每个主题够不够铺满最大网格、同一主题内有没有重复词

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 + 打印样式（`@media print`） |
| `logic.js` | 纯函数：洗牌、抽词、排卡、连线判定、拼音对齐。不碰 DOM，浏览器和 node 都能加载 |
| `words.js` | 词库数据 |
| `app.js` | 界面交互 |
| `test.js` `words.test.js` | 测试 |

全部用普通 `<script>` 标签加载，**不用 ES modules** —— 这样 `file://` 直接双击打开也能跑
（ES modules 会被浏览器的同源策略拦掉）。
